CodexWorkResumer v1.3.1（Build 15）- Windows x64 安裝說明
=========================================================

需求
----
- Windows 10 / 11 x64
- 已安裝並至少啟動過一次 Codex App
- 不需要預先安裝 Go、Node.js 或其他開發工具
- 一般使用者權限即可安裝

安裝
----
1. 將 ZIP 完整解壓縮到一般資料夾；不要直接在壓縮檔預覽中執行。
2. 雙擊「安裝.cmd」。一般官方後台模式下，Codex 可以保持開啟；安裝程式會驗證檔案完整性並啟動背景服務。
3. 只有舊版 Codex 正連接既有的「Codex自動續跑助手」通道時，升級才會提示先關閉 Codex，以免中斷該通道。
4. 安裝完成後，Windows 通知區會出現 CodexWorkResumer 圖示。
5. 單擊或雙擊系統匣圖示開啟主畫面；右鍵顯示控制選單。
6. 內嵌 Mini Monitor 已移除；主畫面仍顯示 5H／Weekly 額度。獨立 Mini Monitor 將另行開發與交付。

Codex自動續跑助手
-----------------
- 這是本機 Codex app-server 恢復通道，不會把資料分享給其他人或上傳到其他服務。
- 新版 Codex 若支援官方 IPC，不需要額外設定。
- 若主畫面顯示 Codex 尚未接入 Codex自動續跑助手，請在設定中啟用並通過健康檢查，再使用「安全啟動Codex.vbs」重新啟動 Codex。
- 若 Codex自動續跑助手關閉或健康檢查失敗，Codex 會維持官方連線；5H／Weekly 額度仍可透過獨立的官方 app-server 讀取。
- Microsoft Store／MSIX Codex 若拒絕直接以共享後台參數啟動，安全啟動器會改走 Windows 官方套件入口，並明示共享通道未建立。它會等使用者自行關閉 Codex，不會強制結束現有工作。
- 可在設定中自行啟用「背景 CLI 備援」。這是預設關閉的次要路徑；只有正式恢復通道不可用時才會在背景繼續同一 Session，結果不會回到原 Codex 視窗。

主要功能
--------
- 對原 Task 原地 Resume，不建立替代對話。
- 暫時性故障、timeout、網路錯誤、server error 自動重試。
- Rate Limit 時等待 resetsAt，重新確認額度恢復後才 Resume。
- 顯示 5H／Weekly 剩餘百分比、reset 時間與倒數。
- 官方額度查詢失敗時，只採用 10 分鐘內的本機快照；沒有新資料就顯示 N/A。
- 可預先勾選正在執行的 Task 以監控額度暫停；勾選不會立即 Resume，可拖曳安排額度恢復後的續跑順序。手動 Resume 使用清單高亮選取；一般暫時故障仍自動救援。
- 額度續跑可選「間隔啟動」（預設 30 秒啟動間隔、可觀測執行上限 2）或「循序完成」；仍由同一個排程器執行。上限只計本程式可觀測的執行工作，無法保證限制外部手動啟動的所有工作。
- 循序模式會在明確正向完成訊號、安靜期及下一次成功掃描確認沒有新活動後自動交棒；這只表示可觀測工作暫時結束，不代表整個專案已完成。額度暫停與待續跑不會被當成完成；網路／逾時等暫時故障自動救援仍保留。
- 主畫面依序分為監控與操作、Session 清單與順序、排程模式與參數、通知與執行紀錄四區；已停止或歷史額度故障不再觸發目前的橘色額度警告。
- 清單會分別標示「本次重試已停止但額度監控仍勾選」及「同一工作續跑的回合成功結束」。已勾選不會自動重啟一筆已停止的重試；續跑成功也不等於整個專案已完成。
- Session 清單在背景更新時保留捲動位置，拖曳會顯示插入位置，切換監控勾選時避免畫面閃動與狀態代碼短暫顯示；安裝後請在實際 Windows 視窗確認。
- 主畫面支援英文與繁體中文。

版本規則
--------
- 公開版本：v1.3.1
- Build：15（只會遞增，不會重複或倒退）
- 完整變更請參閱安裝內容中的 CHANGELOG.md。

解除安裝
--------
- 雙擊「卸載.cmd」會移除程式與啟動項，預設保留設定、狀態與 Log。
- 如需一併移除執行資料，請執行：
  powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\uninstall-release.ps1 -RemoveData

安全與隱私
----------
- 安裝程式會以 SHA256SUMS.txt 驗證套件檔案。
- 工具在本機執行，不會讀取、儲存或上傳使用者訊息、程式碼內容、工具參數或 API 金鑰。
- Log 會限制大小並輪替。
